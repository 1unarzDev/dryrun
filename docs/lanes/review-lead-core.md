## Probed and holding

- **Prohibitions in translation:** prohibition styling is the same in en, es and vi on every immediate-action list. The lead had already fixed this; it now classifies from the source-language text, at `PlanBuilder.swift:104-106`. The probe now runs as a plain regression check. Remaining weakness: classification is still an English keyword heuristic ("never", "do not", "don't"). "Avoid…", "Stay off…" and "Turn around…" are not detected. Recommendation: make the style explicit, as authored metadata on each key (e.g. a `plan.json` sidecar with `{"style":"prohibition"}`).
- **Private notes:** `carePlanNotes` never appears in any title, heading or line, in en, es or vi, without consent. With consent it does appear. The validator agrees.
- **Banners:** across all six scenarios in es and vi, the draft banner is always present, and the fallback note is present whenever any line falls back. Headings and titles are tracked by the `Builder`. One gap: `PlanSection.containsFallback` / `containsDraft` look only at lines, so a UI using those per-section flags would miss a fallback heading. The document-level banner still covers it.
- **Cursor:** with all decisions answered, it finishes, and `currentMinute` equals the last event.
- **Gate:** older tickets are rejected; `invalidate()` rejects everything outstanding.
- **Confirmation:** `.skip` changes nothing and does not bump the revision. `confirmPortal` refuses openings that have an unknown side. Nothing becomes verified without an explicit answer.

## Notes for the simulation/UI boundary (Agent A's lane)

- A counterfactual "Try this change" replay can carry a choice override inside its intervention (relocation). `RehearsalCursor.pendingDecision` only checks `input.choices`, so stepping through a **modified** replay would still stop at a decision the replay has already taken. Show comparisons as a diff (the current UI does), or have the cursor also honour intervention choice overrides.
